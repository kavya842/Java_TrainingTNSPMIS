Step 5: Write the JUnit 5 test class
File: CalculatorTest.java

Location: src/test/java/CalculatorTest.java relative to the project root.

import org.junit.jupiter.api.Test;

import static org.junit.jupiter.api.Assertions.*;

public class CalculatorTest {

    Calculator calculator = new Calculator();

    @Test
    void testAdd() {
        assertEquals(5, calculator.add(2, 3));
    }

    @Test
    void testDivide() {
        assertEquals(2, calculator.divide(10, 5));
    }

    @Test
    void testDivideByZero() {
        assertThrows(
            IllegalArgumentException.class,
            () -> calculator.divide(10, 0)
        );
    }
}



Explanation of the test code
1. @Test

Identifies a method that JUnit should execute as a test.

2. assertEquals(expected, actual)

Checks whether the actual result matches the expected result.
assertEquals(5, calculator.add(2, 3));


Expected result: 5

Actual result: 5

Therefore, the test passes.

3. assertThrows()

Checks whether a particular exception is thrown.
assertThrows(
    IllegalArgumentException.class,
    () -> calculator.divide(10, 0)
);


This test passes when dividing by zero throws IllegalArgumentException.

Our test class contains three tests: addition, division, and division by zero.
Step 6: Understand the pom.xml file
The pom.xml file is the central configuration file for a Maven project.

POM stands for Project Object Model.

It tells Maven the project's identity, Java version, dependencies, and build plugins.

Here is the configuration we used:

         xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 https://maven.apache.org/xsd/maven-4.0.0.xsd">

    <modelVersion>4.0.0</modelVersion>

    <groupId>learning.calculator</groupId>
    <artifactId>deutschland</artifactId>
    <version>1.0-SNAPSHOT</version>

    <properties>
        <maven.compiler.release>17</maven.compiler.release>
        <project.build.sourceEncoding>UTF-8</project.build.sourceEncoding>
        <junit.version>5.10.2</junit.version>
    </properties>

Step 8: Understand the Maven lifecycle
Maven has a sequence of build phases.

Compile

Convert Java source code into .class files.



Test

Run automated tests using JUnit.



Package

Create a distributable artifact such as a JAR.



When you run mvn package, Maven executes the earlier required phases, including compilation and testing, before packaging the artifact.
